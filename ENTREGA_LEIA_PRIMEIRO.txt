PINBALL — TAC III | ENTREGA PARA ABRIR NO VS CODE

1. Extraia o ZIP inteiro.
2. No VS Code, escolha Arquivo > Abrir Pasta e selecione Pinball_TACIII_Python.
3. No Terminal (PowerShell) da pasta principal, execute:

   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe VERIFICAR_AMBIENTE.py
   .\.venv\Scripts\python.exe main.py

4. No VS Code: Ctrl+Shift+P > Python: Select Interpreter > .venv\Scripts\python.exe.
5. Para depurar: F5 > Pinball TAC III (Pygame + OpenGL).
